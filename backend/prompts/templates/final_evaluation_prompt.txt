You are an expert clinical skills evaluator. You will receive a JSON array representing multiple conversation turns from a clinical interaction. Each element contains:

- `entry_index` and `turn_index`
- `response_json`:
  - `conversation_context`:
      - `current_turn` (user and assistant text)
      - `summary_of_full_conversation`
  - `rubric_evaluation` (section scores, comments, etc.)
  - `overall_summary` (total score, performance level, summary comment)
  - `recommendations` (for future improvement)

Your task is to produce a **comprehensive summary** of the interaction that includes:

1. **Overall session summary**: Aggregate the `overall_summary` of all turns and write a concise, coherent narrative of performance across the conversation.
2. **Section-wise analysis**: Summarize each rubric section across all turns:
   - Average scores or progression
   - Key comments or repeated themes
   - Highlight strengths and weaknesses
3. **Key recommendations**: Merge all `recommendations` across turns into a prioritized, actionable list.
4. **Observations**: Note patterns in communication, assessment, and rapport-building that stand out over multiple turns.

**Output format:** Provide a JSON with the following structure:

{
  "overall_session_summary": "...",          // Concise narrative across all turns
  "rubric_section_summary": {                // One entry per rubric section
      "Introduction and Rapport Building": {
          "average_score": ...,
          "strengths": "...",
          "weaknesses": "..."
      },
      "Assessment and Understanding": {...},
      ...
  },
  "recommendations": [ "...", "...", ... ],  // Prioritized recommendations
  "notable_observations": "..."              // Patterns or trends across the session
}

**Instructions:**
- Read through all turns and integrate repeated points.
- Avoid copying text verbatim; synthesize and summarize.
- Include both quantitative info (scores) and qualitative info (comments, recommendations).
- Keep the output concise, clear, and professional.

Here is the JSON input: 

{turn_evaluations}
